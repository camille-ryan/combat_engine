# Reading the board

Readers in `combat_engine.engine.query`, which is the other half of what a row calls. Nothing here changes anything.

## who, and whose side

- `query.active(world: 'World', eid: 'int') -> 'list[Condition]'`
  - (no docstring)
- `query.alive(world: 'World', eid: 'int') -> 'bool'`
  - (no docstring)
- `query.allies(world: 'World', eid: 'int', *, companions: 'bool' = False) -> 'list[int]'`
  - Allies never include the creature itself, nor anybody's companion.
- `query.combatants(world: 'World') -> 'list[int]'`
  - The narrower question: who takes turns and decides the fight.
- `query.conscious(world: 'World', eid: 'int') -> 'bool'`
  - (no docstring)
- `query.creatures(world: 'World') -> 'list[int]'`
  - Everything that can be targeted, flanked, covered or walked around.
- `query.enemies(world: 'World', eid: 'int') -> 'list[int]'`
  - (no docstring)
- `query.feat_categories() -> 'dict[str, str]'`
  - Every feat's printed category, by ref, from the database.
- `query.feats_of(world: 'World', eid: 'int', category: 'str' = '') -> 'tuple[str, ...]'`
  - The feats this creature has, by ref, optionally of one category.
- `query.is_(world: 'World', eid: 'int', c: 'Condition') -> 'bool'`
  - (no docstring)
- `query.is_conjuration(world: 'World', eid: 'int') -> 'bool'`
  - (no docstring)
- `query.is_trap(world: 'World', eid: 'int') -> 'bool'`
  - (no docstring)
- `query.kinds_of(world: 'World', eid: 'int') -> 'frozenset[str]'`
  - A creature's type words: undead, goblin, beast, natural, and so on.
- `query.level_term(world: 'World', eid: 'int', scale: 'str') -> 'int'`
  - What this creature's level is worth, under the current setting.
- `query.living(world: 'World', eid: 'int') -> 'bool'`
  - Is this a living creature? Ten rows print the word as a restriction.
- `query.on_build(world: 'World', eid: 'int', choice: 'str') -> 'bool'`
  - Does this character stand on that leg of its class's fork?
- `query.printed_kinds() -> 'frozenset[str]'`
  - Every type word the corpus prints, from the database.
- `query.race_of(world: 'World', eid: 'int') -> 'str'`
  - A character's race, by ref -- `r4` -- or `""` for anything without one.
- `query.race_sizes() -> 'dict[str, str]'`
  - Every printed race's ref and size word, from the database.
- `query.race_skills(race: 'str') -> 'tuple[tuple[str, int], ...]'`
  - Which skills that race is good at, as `(skill, bonus)` pairs.
- `query.races_sized(size: 'str') -> 'tuple[str, ...]'`
  - Every race of that printed size, by ref, in ref order.
- `query.scenery(world: 'World', kind: 'str' = '', *, within: 'int' = 0, of: 'int | None' = None, loose: 'bool' = False) -> 'list[int]'`
  - What is standing on the map that is not a creature.
- `query.stat_block(world: 'World', eid: 'int') -> 'dict[str, Any]'`
  - The compendium row behind a creature, or `{}` if it has none.
- `query.targetable(world: 'World', eid: 'int') -> 'bool'`
  - Can a power be aimed at this, and land on it?
- `query.team(world: 'World', eid: 'int') -> 'Team | None'`
  - (no docstring)
