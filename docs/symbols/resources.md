# Resources, actions and turns

Things a creature spends, and the budget it spends them from.

## surges and hit points

- `c.regain_surge(self, count: 'int' = 1, *, on: 'int | None' = None) -> 'int'`
  - "Each target regains a healing surge." Returns how many it now has.
- `c.second_wind(self, *, on: 'int | None' = None, cost: 'ActionType' = <ActionType.STANDARD: 'standard'>) -> 'bool'`
  - Take a second wind: a surge, and +2 to AC until your next turn.
- `c.spend_surge(self, *, on: 'int | None' = None) -> 'bool'`
  - Spend a surge and gain nothing for it.
- `c.surge(self, *, on: 'int | None' = None, bonus: 'int' = 0) -> 'int'`
  - Spend a healing surge: a quarter of maximum hit points.
- `c.surge_value(self, of: 'int | None' = None) -> 'int'`
  - A quarter of that creature's maximum, which is what a surge heals.

## power points and augments

- `c.augment: int`
  - how many power points this use was augmented by, or 0.
- `c.augmented(self, ref: 'str', *, of: 'int | None' = None) -> 'int'`
  - What bought the **latest** use of that row. 0 for an unaugmented one.
- `c.lend_augment(self, ref: 'str', cost: 'int', clause: 'Callable[[Cast], None]', *, on: 'int | None' = None, until: 'When' = <When.ENCOUNTER: 'end of encounter'>) -> 'Effect | None'`
  - "Your <power> gains the augmentable keyword": lend it a clause.
- `c.points(self, *, of: 'int | None' = None) -> 'int'`
  - How many power points this creature has left.
- `c.points_spent(self, ref: 'str', *, of: 'int | None' = None) -> 'int'`
  - How many points augmented that row this encounter.
- `c.regain_points(self, n: 'int' = 1, *, on: 'int | None' = None) -> 'int'`
  - "You regain 1 power point." Yours, so it defaults to the caster.
- `c.spend_points(self, n: 'int', *, who: 'int | None' = None) -> 'int'`
  - Spend power points to augment this row. Returns how many went.
- `c.spend_shrouds(self) -> 'int'`
  - Invoke them: the count goes, and what it was is returned.
- `c.transfer_points(self, n: 'int', *, on: 'int | None' = None) -> 'int'`
  - "You transfer 1 or 2 power points to the target."

## charges and per-day uses

- `c.ammunition(self, ev: 'Any' = None) -> 'bool'`
  - Was that shot fired from the ammunition **this row belongs to**?
- `c.charge_left(self, key: 'str', limit: 'int' = 1) -> 'int'`
  - How much of a per-encounter charge is left, for this creature.
- `c.per_day_left(self, ref: 'str', limit: 'int') -> 'int'`
  - How many of a daily allowance are left today, for this creature.
- `c.restore_charge(self, key: 'str', *, on: 'int | None' = None) -> 'bool'`
  - Hand a spent charge back. False if none had been spent.
- `c.restore_use(self, ref: 'str', *, on: 'int | None' = None) -> 'bool'`
  - "You regain the use of your second wind."
- `c.spend_charge(self, key: 'str', limit: 'int' = 1, *, on: 'int | None' = None) -> 'bool'`
  - Take one from a per-encounter charge. False when none is left.
- `c.spend_per_day(self, ref: 'str', limit: 'int') -> 'bool'`
  - Take one from a daily allowance. False when none is left.

## actions and turns

- `c.action_point(self, cost: 'ActionType' = <ActionType.STANDARD: 'standard'>, *, who: 'int | None' = None) -> 'bool'`
  - Spend an action point for an extra action. Yours, so it defaults
- `c.action_points(self, *, of: 'int | None' = None) -> 'int'`
  - How many action points this creature could spend right now.
- `c.end_turn(self) -> 'bool'`
  - "Your turn ends when you use this power."
- `c.extra_action(self, cost: 'ActionType' = <ActionType.MOVE: 'move'>, *, on: 'int | None' = None) -> 'bool'`
  - "You can take an extra move action."
- `c.extra_turn(self, at: 'int') -> 'bool'`
  - Act again this round, at that initiative count. Solos do this.
- `c.grant_action(self, what: 'str', cost: 'ActionType', *, squares_: 'int' = 1, on: 'int | None' = None, until: 'When' = <When.STANCE: 'stance'>) -> 'Effect | None'`
  - Let a creature do an ordinary thing for a different action.
- `c.grant_action_point(self, count: 'int' = 1, *, on: 'int | None' = None) -> 'int'`
  - "The target gains 1 action point", outside the encounter's limit.
- `c.initiative(self, amount: 'int', *, on: 'int | None' = None) -> 'int'`
  - "Each target gains a +10 bonus to his or her initiative check."
- `c.payment_window(self, *, per_turn: 'bool' = False) -> 'object'`
  - The window a "once per round" or "once per turn" payout sits in.
- `c.swap_initiative(self, other: 'int') -> 'bool'`
  - "You and one ally switch places in the initiative order."

## cards and carried things

- `c.draw(self, ref: 'str' = '', *, on: 'int | None' = None) -> 'bool'`
  - Take a stowed weapon up, paying nothing for it.
- `c.draws_free(self, *, cost: 'ActionType' = <ActionType.FREE: 'free'>, per_turn: 'int' = -1, only: 'str' = '', on: 'int | None' = None, until: 'When' = <When.ENCOUNTER: 'end of encounter'>) -> 'Effect | None'`
  - Make taking a weapon up cost less than the printed minor action.
- `c.give(self, ref: 'str' = '', fn: 'Callable[[int], None] | None' = None, *, on: 'int | None' = None, uses: 'int' = 1, cost: 'ActionType' = <ActionType.MINOR: 'minor'>) -> 'int'`
  - Put a one-shot in somebody's hands for them to spend later.
- `c.recall_weapon(self, *, within: 'int' = 0, on: 'int | None' = None) -> 'bool'`
  - Call a weapon that was yours back into your hand from a distance.
- `c.stow(self, ref: 'str' = '', *, on: 'int | None' = None) -> 'bool'`
  - Put a held weapon away. `draw` read backwards.
