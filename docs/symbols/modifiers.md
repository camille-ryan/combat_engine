# Modifiers and refusals

Numbers added to or taken off a roll, and permissions withdrawn. A modifier nothing reads is this component's commonest bug -- if you add a key, add its reader in the same commit.

> Generated by `scripts/symbols.py`. Do not edit: `check.py` fails
> when a committed file and the code disagree. `--write` rewrites it.
