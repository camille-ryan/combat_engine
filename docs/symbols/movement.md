# Movement

Verbs that move a creature. The **mode** it travels in -- fly, swim, burrow -- is not a verb; see the modes section.

> Generated by `scripts/symbols.py`. Do not edit: `check.py` fails
> when a committed file and the code disagree. `--write` rewrites it.

## voluntary -- the creature spends its own movement

- `c.charge: bool`
  - is this use a charge?
- `c.charge_at(self, victim: 'int', ref: 'str' = '', *, who: 'int | None' = None) -> 'bool'`
  - Run at somebody and swing, with the swing marked as a charge.
- `c.flee(self, squares_: 'int', *, on: 'int | None' = None) -> 'int'`
  - The target runs, under its own power, as far from you as it can.
- `c.hover(self, squares_: 'int' = 0, *, on: 'int | None' = None, until: 'When' = <When.EONT: "end of source's next turn">, sustain: 'ActionType | None' = None) -> 'Effect | None'`
  - Go up and stay up. Yours, so it defaults to the caster.
- `c.jump(self, squares_: 'int', *, on: 'int | None' = None, toward: 'int | None' = None, away_from: 'int | None' = None) -> 'int'`
  - A jump: ground crossed rather than walked over.
- `c.move(self, squares_: 'int', *, who: 'int | None' = None, at: 'str' = '', toward: 'int | None' = None, away_from: 'int | None' = None) -> 'int'`
  - Walk. `at` names a movement mode to travel at instead.
- `c.moving_as(self, mode: 'str', *, on: 'int | None' = None) -> 'bool'`
  - Is this creature moving that way **right now**?
- `c.overrun(self, to: 'Square | None' = None) -> 'list[int]'`
  - Trample: walk through whoever is in the way, and say who that was.
- `c.ride(self, *, on: 'int | None' = None) -> 'bool'`
  - Get on. The mount carries you when it moves.
- `c.rise(self, squares_: 'int', *, on: 'int | None' = None) -> 'int'`
  - Go up, and stay there. Yours, so it defaults to the caster.
- `c.run_at(self, victim: 'int', *, who: 'int | None' = None) -> 'bool'`
  - Walk into reach of a named creature, the way a charge's move does.
- `c.shift(self, squares_: 'int' = 1, *, who: 'int | None' = None, to: 'Square | None' = None, toward: 'int | None' = None, away_from: 'int | None' = None, share: 'bool' = False) -> 'bool'`
  - Shift, choosing the destination through the world's decider.
- `c.shift_as(self, cost: 'ActionType', squares_: 'int' = 1, *, on: 'int | None' = None, until: 'When' = <When.STANCE: 'stance'>) -> 'Effect | None'`
  - "You can shift 2 squares as a move action."
- `c.teleport(self, squares_: 'int', *, who: 'int | None' = None, to: 'Square | None' = None, toward: 'int | None' = None, away_from: 'int | None' = None, share: 'bool' = False) -> 'bool'`
  - Blink somewhere. `to` names the square, as `c.shift` already allowed.
- `c.walk_toward(self, target: 'int | Square', squares_: 'int' = 0, *, on: 'int | None' = None) -> 'int'`
  - Compelled: the creature walks the most direct route, no choice.

## forced -- somebody else moves it

- `c.bull_rush(self, *, on: 'int | None' = None) -> 'bool'`
  - "Push the target 1 square, and shift into the vacated space."
- `c.pull(self, squares_: 'int', *, on: 'int | None' = None, anchor: 'Square | None' = None, to: 'Square | None' = None, by: 'int | None' = None) -> 'int'`
  - `to` names the destination outright, for a row that does.
- `c.push(self, squares_: 'int', *, on: 'int | None' = None, anchor: 'Square | None' = None, to: 'Square | None' = None, by: 'int | None' = None) -> 'int'`
  - `to` names the destination outright, for a row that does.
- `c.slide(self, squares_: 'int', *, on: 'int | None' = None, anchor: 'Square | None' = None, to: 'Square | None' = None, toward: 'int | None' = None, by: 'int | None' = None) -> 'int'`
  - `to` names the destination outright, for a row that does.

## falling

- `c.fall(self, squares_: 'int' = 0, *, on: 'int | None' = None, safe: 'bool' = False) -> 'int'`
  - Come down, with everything that costs. Follows `c.target`.

## how far, and what stops it

- `c.any_size_manoeuvre(self, *, on: 'int | None' = None, until: 'When' = <When.ENCOUNTER: 'end of encounter'>) -> 'Effect | None'`
  - "You can bull rush targets of any size."
- `c.blocks_entry(self, *, on: 'int | None' = None, until: 'When' = <When.ENCOUNTER: 'end of encounter'>) -> 'Effect | None'`
  - "An enemy cannot enter this creature's space by any means."
- `c.extend_every(self, kind: 'str', squares_: 'int', *, on: 'int | None' = None, until: 'When' = <When.ENCOUNTER: 'end of encounter'>, when: 'Callable[[dict[str, Any]], bool] | None' = None) -> 'Effect | None'`
  - Lengthen **every move of a kind**. `c.extend_every("shift", 1)`.
- `c.extend_move(self, ref: 'str', squares_: 'int', *, on: 'int | None' = None, until: 'When' = <When.ENCOUNTER: 'end of encounter'>, when: 'Callable[[dict[str, Any]], bool] | None' = None) -> 'Effect | None'`
  - Make a named row move you further. `c.extend_move("p1449", 5)`.
- `c.forces(self, squares_: 'int' = 1, *, on: 'int | None' = None, until: 'When' = <When.ENCOUNTER: 'end of encounter'>, when: 'Callable[[dict[str, Any]], bool] | None' = None) -> 'Effect | None'`
  - Lengthen every push, pull and slide this creature makes.
- `c.ignores_difficult(self, kind: 'str' = '', *, made_by: 'str' = '', on: 'int | None' = None, until: 'When' = <When.ENCOUNTER: 'end of encounter'>, when: 'str' = '') -> 'Effect | None'`
  - Cross rough ground for nothing. `kind` names which sort, or all.
- `c.ignores_difficult_in(self, zone: 'int', *, side: 'str' = 'team') -> 'None'`
  - "You and your allies can ignore difficult terrain in the zone."
- `c.immovable(self, *, until: 'When' = <When.EONT: "end of source's next turn">, on: 'int | None' = None) -> 'Effect | None'`
  - Cannot be pushed, pulled or slid. The counterpart of `c.no_provoke`.
- `c.may_enter(self, *, sizes: 'Sequence[Size]' = (), side: 'str' = '', on: 'int | None' = None, until: 'When' = <When.ENCOUNTER: 'end of encounter'>) -> 'Effect | None'`
  - "Can enter enemies' spaces during its movement" -- the mover's
- `c.no_walk(self, *, until: 'When' = <When.EONT: "end of source's next turn">, on: 'int | None' = None) -> 'Effect | None'`
  - "It cannot use move actions to walk or run." It may still shift.
- `c.phasing(self, *, until: 'When' = <When.ENCOUNTER: 'end of encounter'>, on: 'int | None' = None) -> 'Effect | None'`
  - Move through earth, rock and anything else in the way.
- `c.resist_forced(self, squares_: 'int' = 1, *, on: 'int | None' = None, until: 'When' = <When.ENCOUNTER: 'end of encounter'>, when: 'Callable[[dict[str, Any]], bool] | None' = None) -> 'Effect | None'`
  - Shorten every push, pull and slide against this creature.
- `c.shares_space(self, *, on: 'int | None' = None, until: 'When' = <When.ENCOUNTER: 'end of encounter'>, difficult: 'bool' = True) -> 'Effect | None'`
  - Anyone may stand in this creature's square, and it costs them.
- `c.speed_of(self, who: 'int | None' = None) -> 'int'`
  - How fast somebody is. **Defaults to the caster**, not the target.
- `c.squares_for(self, ref: 'str' = '', default: 'int' = 0, ctx: 'dict[str, Any] | None' = None) -> 'int'`
  - How far this row moves this creature, after anything lengthening it.

## modes and mounts

- `c.lose_mode(self, name: 'str', *, until: 'When' = <When.EOTNT: "end of target's next turn">, on: 'int | None' = None) -> 'Effect | None'`
  - Take a way of moving away for a while, and give it back.
- `c.mode(self, name: 'str', speed: 'int', *, until: 'When' = <When.ENCOUNTER: 'end of encounter'>, on: 'int | None' = None) -> 'Effect | None'`
  - Grant a way of moving -- fly, swim, climb -- for a while.
- `c.mount(self) -> 'int | None'`
  - Whatever this creature is riding.
- `c.move_companion(self, squares_: 'int') -> 'int'`
  - Walk the companion. It has a speed of its own and no turn to use it.

## movement modes -- strings, not verbs

There is no `c.fly`. A mode is a key in `Speed.modes` with its own
speed, granted by `c.mode(name, speed)` and travelled with
`c.move(at=...)`. `c.moving_as(mode)` asks which one is in use.

  `burrow`, `climb`, `fly`, `hover`, `levitate`, `swim`

- **leaves the ground, so it passes over whoever is standing in
  the way** (`movement.OVERHEAD`): `burrow`, `fly`, `swim`. Teleport is not one of these -- it has no path to pass along,
  so it has to arrive somewhere it fits.
- **does not fall** (`falling.AIRBORNE`): `climb`, `fly`, `hover`, `levitate`. Climbing counts: a creature on a wall is holding on, which is
  the state an arrested fall leaves it in.

The two sets are **not** nested and neither is 'airborne' in the
English sense -- `burrow` leaves the ground and still falls;
`climb` does not leave it and does not fall.
