# Gates -- the `when=` context

Almost every modifier takes `when=lambda ctx: ...`. This is the whole vocabulary a gate may read.

> Generated by `scripts/symbols.py`. Do not edit: `check.py` fails
> when a committed file and the code disagree. `--write` rewrites it.

## `when=` context keys

A gate is `when=lambda ctx: ...`. The ctx is a plain dict, so a key
that is not written is not an error -- the gate is simply never
true, and the row lays its effect and does nothing. `m5788a0` reads
`ctx["vs"]`, which nothing writes, so its immunity has never
applied (#591). `symbols.py` refuses a key that is not listed here.

- `ctx['ability']` -- which ability scored the roll.
- `ctx['action_point']` -- was an action point spent on this.
- `ctx['actor']` -- whoever is acting, on a ctx built from a non-attack event.
- `ctx['advantage']` -- did the attack have combat advantage.
- `ctx['ammo']` -- the ammunition used.
- `ctx['among']` -- the set a choice was made from.
- `ctx['as_']` -- the action it is being taken as.
- `ctx['attacker']` -- who is swinging. `target` is who it lands on.
- `ctx['branch']` -- which half of a melee-or-ranged row is in use.
- `ctx['charge']` -- is this use a charge.
- `ctx['conditions']` -- the conditions in play for this read.
- `ctx['crit']` -- was it a critical hit.
- `ctx['dtype']` -- the damage type of this blow.
- `ctx['dtypes']` -- every type of a blow that is several at once.
- `ctx['effect']` -- the effect being asked about.
- `ctx['from_attack']` -- did this come out of an attack.
- `ctx['granted_by']` -- who handed this creature the attack, or -1.
- `ctx['granted_via']` -- the ref of the row that handed it over -- an attack, or since #672 a **saving throw**. `Cast.save` writes it from its own `ref`, the way `Effect.by` does, and it is empty for the ordinary end-of-turn throw nobody granted.
- `ctx['hand']` -- which hand the weapon is in.
- `ctx['how']` -- the kind of forced movement -- push, pull, slide.
- `ctx['keywords']` -- the keywords of the row or effect being asked about.
- `ctx['kind']` -- the kind of action or roll. See `Cast.does_not_provoke`.
- `ctx['label']` -- the label of the effect being asked about.
- `ctx['mode']` -- the movement mode in use.
- `ctx['mover']` -- who is trying to enter a square. `movement.may_enter`.
- `ctx['occupant']` -- who is standing in it. The other half of `mover`.
- `ctx['ongoing']` -- is this ongoing damage rather than a blow.
- `ctx['opportunity']` -- is this an opportunity attack.
- `ctx['power']` -- the ref of the row doing this. The commonest gate.
- `ctx['ranged']` -- was it a ranged attack.
- `ctx['reach']` -- the shape of the attack -- `Range.kind` verbatim.
- `ctx['reroll_by']` -- the ref of whatever asked for the reroll.
- `ctx['skill']` -- the skill being checked, lowercased.
- `ctx['source']` -- who laid the effect.
- `ctx['target']` -- who it lands on. The commonest key in the tree.
- `ctx['when_']` -- where in the turn a saving throw was taken -- `"end"` for the ordinary one, `"early"` for one moved or granted at the start. Written by `Effects.save` and `Cast.save`, which take it as a keyword. Named with the trailing underscore for `Event.kind`'s reason: a field called `when` shadows the property `wire()` puts in every replay envelope. #671.
- `ctx['why']` -- the reason recorded for this.
