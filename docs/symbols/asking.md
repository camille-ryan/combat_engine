## what the call already knows -- state, not calls

- `c.declared_feats: dict[str, str]`
  - the feat already picked for each bracketed category this use, so `c.declare` asks once and every later clause honours the same answer.
- `c.me: int`
  - the caster's eid. `on=c.me` aims a target-defaulting method back at you.
- `c.ref: str`
  - this row's own id.
- `c.targets: list[int]`
  - **every** target of this one use, as a list -- what "if you hit two creatures" needs. `c.target` is one of them.
- `c.world: World`
  - the world itself. Prefer the methods above; reach for this last.

## rolling and the trigger

- `c.ability_check(self, ability: 'Ability', dc: 'int' = 0, *, who: 'int | None' = None, bonus: 'int' = 0)`
  - Roll a raw ability check. Truthy when it beat the DC.
- `c.check(self, skill: 'str', dc: 'int' = 0, *, who: 'int | None' = None, bonus: 'int' = 0, against: 'int | None' = None)`
  - Roll a skill check. Truthy when it beat the DC.
- `c.opportunity: bool`
  - is this use an opportunity attack?
- `c.ranged`
  - Is this use a ranged one? Asks the branch, not the keywords.
- `c.roll(self, dice: 'str | int') -> 'int'`
  - Roll dice and get the number, without applying it to anybody.
- `c.struck_by(self, ev: 'Any', *, kind: 'str' = '', ref: 'str' = '', basic: 'bool' = False) -> 'bool'`
  - What kind of blow caused this event? Reads its `power`.
- `c.struck_by_property(self, prop: 'str', ev: 'Any' = None) -> 'bool'`
  - Did the attack behind this event use a weapon with that property?
- `c.struck_with(self, ev: 'Any' = None) -> 'Weapon | None'`
  - The weapon or implement the triggering attack was made with.
- `c.trigger: Any`
  - the event being answered, on an interrupt or reaction.
